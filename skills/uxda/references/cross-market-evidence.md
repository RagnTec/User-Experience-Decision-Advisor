# Cross-Market Evidence Gate | v0.4A

Applies when a decision compares, exports to, or reuses evidence from differing geographic/cultural markets. Use a target-market-specific interpretation instead of essentializing 'Eastern'/'Western' users.

## Evidence routing and comparability
- First identify target country/region, product category, customer segment, channel, use infrastructure, language and reference date **only where they can affect the current choice**. When absent, offer symmetric conditional branches; if market selection itself is the goal, propose a short list of decision criteria instead of fabricating a chosen market.
- Sort each input: project fact, sourced local fact (jurisdiction/date/sample), industry analogy, hypothesis, unsupported stereotype. A familiar practice in one country is not a universal behavior or a confirmed product requirement.
- Compare markets only if category, user group, purchase/usage phase, sampling frame, metric definition, time window and currency/purchasing-power context are compatible. Mark unavailable comparators as 'not established'.
- For translated surveys, check semantic equivalence, response styles and **measurement comparability/invariance when justified** before interpreting score differences as cultural differences; do not claim statistical invariance without actual testing.
- Compliance: jurisdiction and product category must be verified from original competent authorities, current version and applicability; a regulator acronym or mark does not certify a particular model. Route legal/regulatory determinations to appropriate expertise.
- Review mining: comments/reviews are self-selected and platform-mediated, not population frequencies or direct return rates. Never infer 'top complaint/return reason' from star counts alone.
- External browsing only when the answer materially needs fresh/local facts, and only use generalized search queries; never paste confidential product briefs into public search.

## Decision-facing output
Name the **actual choice** (e.g., choose country A vs B, prioritize serviceability vs added feature). For each relevant factor show claim, exact supporting scope, conflicting possibility, implication and cheap next evidence that could reverse choice. If none of the local evidence can distinguish options, recommend a limited comparison rather than categorical product-market fit statements.
