# Evidence, Traceability & Uncertainty | v0.3

这是为设计讨论创建的**来源和推论隔离规则**，不是学术通用的「证据等级认证」。在实际任务中使用自然中文，不向普通协作方强加术语代号。

## 1. 证据类型（不简单线性排名）

| 类型 | 使用条件 | 可写 | 不可写 |
|---|---|---|---|
| 直接材料事实 | 实际看到的截图、原型、流程、字段、文案 | “所提供的页面出现‘继续’按钮” | “用户因此无法理解” |
| 利益相关者陈述 | 使用者或团队介绍设计、定位、约束 | “据任务说明，目标为首次使用者” | “已经独立证实目标用户如此” |
| 实际用户观察 | 访谈/可用性测试/观察/调查/日志附方法及记录 | “本次观察中，2/5 人尝试返回” | “40% 总体用户会返回” |
| 公开方法或科学依据 | 可访问、已确认范围的公共知识 | “该启发式可用于排查状态反馈” | “违反该启发式=实验已证实失败/不合规” |
| 分析推断 | 基于任务条件的心理/行为机制推导 | “该标签可能增加选择歧义” | “用户一定误点” |
| 待验证假设 | 有可反驳结果和验证途径 | “若反馈缺失，可能降低完成状态可见性” | 直接宣布机制和发生比例 |
| 未知与冲突 | 未提供/证据冲突/无法访问 | “当前材料未显示确认状态” | “系统没有确认状态” |

用户研究数据若是来自当前授权输入，应交代资料来源、样本/任务与限度。公开权威来源说明框架，不等于替代本产品真实用户研究。

## 2. 内部判断记录（Evidence-to-Decision Trace）

只记录重要发现：

`Finding ID | Source pointer | What is actually observed/said | User goal/task step | Hypothesized mechanism + rival explanation | Consequence if true | Scope | Evidence support | What would change the option`

示例（合成）：

`F1 | 设计图 P2 | 取消弹窗按钮为“继续”“返回” | 确认取消 | “继续”目标不明确；替代解释是上文已解释清楚 | 可能误选操作 | 仅所见弹窗 | 设计事实可靠；误选仅假设 | 验证任务误选或出现相关投诉后优先修订按钮`。

不要混淆「来源是否清楚」「机制是否合理」「结论是否有数据证明」。**无法读到附件时必须承认未读取，不得引用其内容。**

## 3. 影响程度与证据支持分离

使用描述性的影响等级，绝不默认量化：

- **任务阻断 / 潜在安全或重要权利影响**：问题若发生，会阻断关键目标、难以恢复，或超出 UX 职权。需明确升级/验证条件；不必先估算概率才能提出注意。
- **任务效率 / 理解与错误恢复影响**：可能增加步骤、判断或错误成本，优先结合任务频率和可恢复性判断，但没有频率数据则写未知。
- **次要摩擦 / 局部视觉与偏好差异**：通常可按目标和资源权衡，除非关联关键人群或更高后果。

证据支持按「直接观察且可追溯 / 多来源一致但有条件 / 仅设计推断 / 尚未可核查」描述；**不将影响程度乘以证据支持程度生成伪科学分数**。

**技术能力不是由形态或惯例自动给定。** 对方案取舍的关键能力，来源可能是用户提供的功能定义、可核对的适用标准或测试材料；若仅来自同类产品的典型配置或对标例子，应标为推测，而不能当作本产品事实。

## 4. 重要反例清单

- 设计图没有展示的状态，可能在真实系统另有处理。
- 受访者的表达可能受情境、提问方式、社会期许与回忆偏差影响；实际使用行为可能不同。
- 已发现的误操作可能来自培训、设备条件、故障、环境干扰，而非界面本身。
- 方案 A 在新手上占优，可能对熟练用户增加操作成本。
- 小样本可用于发现问题，**不能凭样本内占比推总体比例**。
- 指标改变可能由同时上线的其他功能、流量构成、选择偏差引起。

## 5. 标准与公开资料

- 核验版本、适用对象和条文可见范围；不得从网页摘要虚构特定条款和合规阈值。
- 公开文献若只有摘要，说明仅核查摘要，不宣称阅读全文。
- **内容版权**：不复制完整标准正文、付费文献或他人的图表；以自己的话概括公开可核验的元信息和适用边界。
- 无网络时，标注“引用待核验”，不捏造论文和 DOI；若判断依赖最新标准，则暂停合规性判断。

## 6. 输出一致性检查

D/E 对同一事实使用相同证据状态，但不必有相同建议。D 可基于资源和可逆性建议暂缓，E 仍可认定设计存在合理的潜在风险。建议旁交代最强反对理由或逆转条件。
