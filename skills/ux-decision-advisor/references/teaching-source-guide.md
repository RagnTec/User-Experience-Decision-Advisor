# Teaching Source Guide | v0.5C — verified public learning entry points, not pre-verified project claims

**Source register is informational only.** On 2026-10-29, the publicly visible web page and the listed scope were checked during package authoring. This does not establish that the future offline Agent has read a site, that links will continue working, or that the sources support future product-specific claims. No live user study, scientific effect size, regulation clause or market statistic is inferred here. The sources provide methods and disciplinary *introductions*, not a substitute for peer-reviewed original work or current compliance review.

For advanced communication and mass-media research these are **introductory educational pointers**, not verified empirical causal studies. When a project requires a factual media mechanism, specific audience behavior or causal claim, read an appropriate original/credible source if browsing is permitted; otherwise mark it as a hypothesis to test. Do not invent classic paper details from memory. Additional domain-specific sources need actual review, bibliographic metadata and examined passage, not a URL-only list.

**Verification process for newly added sources:** (1) confirm title/authors/publisher/date/version; (2) actually open relevant page or provided file; (3) check accessible body rather than a login, blank page or abstract-only gate; (4) record section/page and precisely supported statement; (5) check whether contradictory authoritative material changes interpretation; (6) distinguish generic framework from a case-specific causal/regulatory claim. For an offline turn, refer to M01–M05 only as *pre-bundled leads*, not 'verified now' unless the source text is supplied and inspected in that turn. Never fabricate URLs, articles or paragraphs.
